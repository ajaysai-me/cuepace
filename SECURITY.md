# Security Policy

## Supported versions

Security fixes go into the latest release. Please update to the newest version before reporting.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through this repository's **Security** tab, using **Report a vulnerability**. Include:

- what the problem is and what an attacker could do with it
- steps to reproduce, or a proof of concept
- the app version and device you tested on

You'll get an acknowledgement within a few days. Once a fix is released, we're happy to credit you in the release notes if you'd like.

## Verifying downloads

Only install CuePace APKs from this repository's **Releases** page. Each release lists the SHA-256 checksum of its APK so you can confirm the file wasn't modified.
